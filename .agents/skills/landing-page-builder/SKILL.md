# Landing Page Builder

Goal:
Create a powerful, conversion-focused landing page.

Structure:
1. Hero (strong hook + CTA)
2. Problem
3. Solution
4. Benefits
5. How it works
6. Social proof
7. CTA
8. FAQ

Rules:
- First screen must be impactful
- CTA must be visible immediately
- Keep text concise
- Use strong headlines
- Sections must be scannable
- Mobile-first layout

Avoid:
- Long boring text blocks
- Weak CTAs
- Confusing flow
