# Design System Guard

Goal:
Protect visual consistency across the project.

Rules:
- Do NOT introduce random colors
- Do NOT change typography arbitrarily
- Do NOT break spacing system
- Reuse existing components
- Keep consistent border radius, shadows, spacing

If missing:
- Extend system cleanly (not randomly)
