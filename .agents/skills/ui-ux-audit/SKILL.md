# UI UX Audit

Goal:
Upgrade any page to a premium, modern, clean, high-conversion interface.

Use this skill when:
- reviewing a page design
- improving layout
- making UI feel more professional
- fixing visual hierarchy issues

Checklist:
- Clear visual hierarchy (headline → sub → CTA)
- Consistent spacing system
- Clean typography scale
- Strong CTA visibility
- No clutter
- Proper section separation
- Balanced layout
- Trust elements (badges, clarity, proof)
- Mobile-first behavior

Rules:
- Do NOT overdesign
- Do NOT break design system
- Prefer minimal clean changes
- Every change must improve clarity or conversion
