# Conversion Copy

Goal:
Make content persuasive and clear.

Rules:
- Focus on benefits, not features
- Keep sentences short
- Use emotional triggers
- Use clear CTAs
- Avoid generic phrases

Examples:
Bad: "We provide digital solutions"
Good: "Turn your website into a 24/7 sales machine"
