# Responsive Fix

Goal:
Ensure perfect behavior on all screen sizes.

Use this skill when:
- layout breaks on mobile
- elements overflow
- buttons misalign
- spacing collapses

Checklist:
- Check navbar
- Check hero section
- Check cards and grids
- Check buttons and padding
- Check typography scaling
- Check touch usability

Rules:
- Do not fix one breakpoint by breaking another
- Keep design consistent
- Use clean responsive logic
- Prefer flexible layouts (flex/grid)
