# StädSync AI keyword research

Updated: 2026-04-28

This file documents the Swedish search-intent clusters used for the StädSync AI indexing work.

## Priority clusters

1. `affärssystem för städföretag`
   - Related terms: `programvara för städföretag`, `branschsystem för städföretag`, `bästa systemet för städföretag`, `system för städbolag`.
   - Landing page: `/stadsync-ai/affarssystem-stadforetag`

2. `RUT XML Skatteverket`
   - Related terms: `XML-fil RUT`, `Skatteverket RUT företag`, `HushallBegaran XML`, `RUT export Skatteverket`.
   - Landing page: `/stadsync-ai/rut-xml-skatteverket`

3. `schemaläggning städföretag`
   - Related terms: `städ schema system`, `planeringsprogram städföretag`, `ruttplanering städ`, `återkommande städuppdrag`.
   - Landing page: `/stadsync-ai/schemalaggning-stadforetag`

4. `tidrapportering städföretag`
   - Related terms: `mobilapp städpersonal`, `digital arbetsorder städ`, `arbetsorder städföretag`, `uppdragshantering städ`.
   - Landing page: `/stadsync-ai/tidrapportering-stadforetag`

5. `personnummer GDPR RUT`
   - Related terms: `GDPR städföretag`, `RUT personnummer`, `kunddata städföretag`, `personuppgifter städ`.
   - Landing page: `/stadsync-ai/personnummer-gdpr-rut`

6. `jämför system för städföretag`
   - Related terms: `bästa systemet för städföretag`, `TimeWave alternativ`, `Tengella alternativ`, `städföretag software`.
   - Landing page: `/stadsync-ai/jamfor-system-stadforetag`

## Search evidence

- Skatteverket documents XML import for rot and rut, including XML schema and import rules:
  `https://www.skatteverket.se/foretag/etjansterochblanketter/allaetjanster/schemalagerxml/rotochrutforetag.4.71004e4c133e23bf6db800063583.html`

- Skatteverket rules page uses terms around XML import, buyer validation, personnummer, payment year, and buyer counts:
  `https://www.skatteverket.se/foretag/etjansterochblanketter/allaetjanster/schemalagerxml/rotochrutforetag/reglerforattimporterafiltillrotochrut.4.76a43be412206334b89800033198.html`

- IMY states that Swedish personal identity numbers are not GDPR-sensitive personal data, but are especially protected in Sweden:
  `https://www.imy.se/verksamhet/dataskydd/det-har-galler-enligt-gdpr/introduktion-till-gdpr/personuppgifter/personnummer/`

- Swedish competitors and market pages commonly use terms such as `system för städföretag`, `affärssystem för städföretag`, `schemaläggning`, `tidrapportering`, `programvara för städföretag`, and comparisons around TimeWave/Tengella/Wisegent.
